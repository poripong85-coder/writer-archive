# 🍊 귤 하우스 — 온라인 집들이

귤껍질 출판사와는 **별개의 단독 페이지**입니다. 이 폴더(`gyul-house/`) 안의 파일만 쓰고, 출판사 사이트와 서로 링크하지 않습니다.

주소 (GitHub Pages): `https://poripong85-coder.github.io/writer-archive/gyul-house/`

1. 중문을 **똑똑**(두 번) 두드리면 유리 너머로 귤 그림자가 다가오며 "누구세요~?"
2. 문짝이 한쪽으로 미끄러져 열리고 귤이 손을 흔들며 나옵니다
3. **집 구경 시작** → 방마다 픽토그램 장면 + 귤의 한마디 (← → 키, 옆으로 밀기도 됨)
4. 마지막 인사 + (선택) 인사 남기기 버튼

## 고치는 곳

[`house.js`](house.js) 한 파일에서 고칩니다.

- `door` — 문짝 수(1~4)·열리는 쪽·아치형·문틀 색·유리(투명/불투명/모루유리)·가로 살 위치·손잡이 색
- `rooms` — 방 이름·귤 대사·사진 주소(`photo`). 장면: `living · kitchen · study · bedroom · veranda`
- `outro.link` — 마지막 버튼 (방명록·오픈채팅·설문 주소 등). `url` 이 비어 있으면 버튼이 안 보입니다

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 |
| `house.js` | 중문·방 내용 |
| `main.js` | 문 열기·투어 동작과 픽토그램 그림 |
| `style.css` | 스타일 (밝은/어두운 화면 자동) |
