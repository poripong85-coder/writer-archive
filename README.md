# 🍊 귤껍질

매일 떠오른 생각 조각을 모아두면, **자정에 하루치가 인사이트 조각으로 아카이브**되는 앱입니다.

카톡 '내게 쓰기'처럼 부담 없이 던져두세요. 글도, 링크도, 사진도 전부 조각이 됩니다.
하루가 끝나면 자동으로 봉인되고, 네이버 캘린더처럼 날짜별로 다시 꺼내볼 수 있습니다.

## 화면

| 오늘 | 달력 | 조각 |
|---|---|---|
| 자유롭게 적는 스트림. 링크는 카드로, 사진은 그리드로 붙습니다. 자정까지 남은 시간이 함께 보입니다. | 월 단위 격자. 조각이 많은 날일수록 칸이 진해지고, 메모·링크·사진을 점으로 표시합니다. 날짜를 누르면 그날 조각이 열립니다. | 봉인된 하루들을 검색하고 태그로 골라 봅니다. |

## 쓰는 법

```bash
npm start           # http://localhost:5173 (python3 http.server)
npm test            # 날짜 경계·파싱·통계 순수 로직 테스트
```

정적 파일뿐이라 GitHub Pages, Netlify, Vercel, 사내 서버 어디에 올려도 그대로 돌아갑니다.
빌드 단계는 없습니다. (ES 모듈이라 `file://`로 직접 열면 안 되고, 서버가 필요합니다.)

휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치됩니다. 설치 후에는 오프라인에서도 열립니다.

## 기록하는 법

- **Enter** 남기기 · **Shift+Enter** 줄바꿈 (한글 조합 중 Enter는 전송되지 않습니다)
- 사진은 **붙여넣기(Ctrl+V)**, 드래그 앤 드롭, 첨부 버튼 셋 다 됩니다. 긴 변 1600px로 줄여 저장합니다.
- `#태그` 를 쓰면 조각 화면에서 태그로 모아 볼 수 있습니다.
- **☆** 를 누르면 그날의 핵심 인사이트로 표시되고, 조각 카드의 첫 줄 요약이 됩니다.
- 단축키: `1` 오늘 · `2` 달력 · `3` 조각 · `Ctrl/⌘+K` 검색

## 자정 아카이브

- 하루 경계는 **기기의 로컬 자정**입니다. 조각은 작성 시각 기준으로 그날에 묶입니다.
- 자정이 지나면 그 전날들이 봉인되고 '인사이트 조각' 카드로 정리됩니다.
- 앱을 켜둔 채로 자정을 넘기면 타이머가 처리하고, 꺼져 있었다면 **다시 열 때** 밀린 날짜를 한 번에 봉인합니다.
  기기가 절전에 들어가 타이머를 놓쳐도 창이 다시 활성화될 때 확인합니다.
- 조각 통계(개수·링크·사진·글자 수·태그)는 볼 때마다 원본에서 다시 계산합니다.
  나중에 글을 고쳐도 카드가 어긋나지 않습니다.

## 데이터

모든 기록은 **이 기기의 브라우저(IndexedDB)** 안에만 남습니다. 서버로 보내지 않고, 계정도 필요 없습니다.
사진은 Blob 그대로 저장합니다.

- 설정 → **백업**: 사진까지 포함한 JSON 한 파일로 내보내고 되돌립니다. 기기를 옮길 때 쓰세요.
  iframe 안에 끼워 열린 경우처럼 파일 저장이 막힌 환경에서는 같은 JSON을 복사하는 창으로 대체됩니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 가끔 백업을 받아두세요.
- 외부로 나가는 요청은 링크 카드의 파비콘 하나뿐이고, 실패해도 첫 글자 아이콘으로 대체됩니다.
