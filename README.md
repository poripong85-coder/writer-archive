# 🍊 귤껍질 출판사

매일의 인사이트 조각을 모으는 작은 출판사 사이트입니다.
홈은 다마고치처럼 작은 도트 마을이고, 귤·별·연필·집 모양 건물이 각각 메뉴로 이어집니다.

| 건물 | 메뉴 | 내용 |
|---|---|---|
| 🍊 귤 | 귤껍질 소개 | 출판사 소개. 편집장이 화면에서 바로 고친다 |
| ⭐ 별 | 일상 조각 모음 | 매일의 조각 기록장 + 나도 기록해보기 |
| ✏️ 연필 | 사부작 책공장 | 편집장이 채우는 소개 페이지 (비어 있으면 "준비 중") |
| 🏠 집 | 시안북스테이 | 편집장이 채우는 소개 페이지 (비어 있으면 "준비 중") |

## 일상 조각 모음

**귤껍질 기록장** — 편집장(관리자)만 쓰고, 모두 읽습니다.
- 편집장: `오늘 쓰기` · `달력` · `조각 모음` 탭. 카톡 '내게 쓰기'처럼 글·링크·사진을 던져두면 자정에 하루치가 조각으로 정리됩니다.
- 방문자: `달력` · `조각 모음`만 보입니다. 날짜를 누르면 그날의 조각이 열립니다.

**나도 기록해보기** — 로그인한 사람마다 자기 기록장이 생깁니다. 기능은 똑같고, 본인만 볼 수 있습니다(편집장도 못 봅니다).

자정 처리: 오늘 이전의 날은 곧 봉인된 날입니다. 앱을 켜둔 채 자정을 넘기거나, 며칠 만에 다시 열면 "지난번 이후 N일치가 조각으로 정리됐어요" 알림이 뜹니다.

## 어디서 어떻게 돌아가나

같은 코드가 실행 환경을 스스로 판단합니다 (`app/env.js`).

| 환경 | 저장 위치 | 관리자 | 나도 기록해보기 |
|---|---|---|---|
| claude.ai 아티팩트 (로그인) | 공유 저장소 (db 기능) + 사진은 assets | 아티팩트 소유자 | 기록 권한 있는 사람마다 따로 |
| claude.ai 아티팩트 (로그아웃) | — | — | 로그인 안내만 표시 |
| 직접 띄움 (`npm start`) | 이 브라우저의 IndexedDB | 실행한 사람 | 같은 브라우저 안에서 체험용 |

아티팩트에 선언한 접근 규칙:

```js
db: { rules: [
  { path: "", read: "view", write: "owner" },          // 공개 기록장·소개 글: 모두 읽기, 소유자만 쓰기
  { path: "data/users/{self}", write: "interact" },     // 각자의 기록장: 본인만 읽고 쓰기
]}
```

`fragments/<id>` 공개 조각 · `pages/<intro|factory|stay>` 소개 글 · `data/users/<id>/<entryId>` 개인 조각

### 공유 설정에서 알아둘 것

- 기록을 **보려면** claude.ai 로그인이 필요합니다. 로그아웃 상태면 마을과 메뉴만 보이고, 기록장 자리에 로그인 안내가 뜹니다.
- **나도 기록해보기로 쓰려면** 그 사람이 이 아티팩트에서 참여자(Contributor) 이상이어야 합니다. 권한이 없으면 쓰는 순간 "기록 권한을 요청해 주세요" 안내가 뜨고, 쓰던 글은 입력창에 남습니다.
  - 팀/엔터프라이즈 플랜: 조직 전체 공유를 참여자로 두면 됩니다.
  - 개인 플랜: 바깥 사람은 링크로 들어오면 읽기만 할 수 있습니다. 쓰게 하려면 이메일로 편집자 초대를 해야 하고, 이 경우 공개 링크는 꺼져 있어야 합니다.
- 방문자가 올린 사진은 조직 구성원에게만 보입니다(플랫폼 정책).

## 로컬에서 띄우기

```bash
npm start      # http://localhost:5173
npm test       # 날짜 경계·파싱·통계·봉인 판정 순수 로직 테스트
```

빌드도 의존성도 없습니다. 정적 파일이라 어디에 올려도 됩니다(이때는 단독 모드).

## 예전 버전 데이터

이 기기에만 저장하던 예전 귤껍질의 조각이 남아 있으면, claude.ai에서 처음 열 때 어디로 옮길지 묻습니다
(공개 기록장 / 나의 기록장 / 나중에). 원본은 지우지 않으며, 설정에서도 언제든 다시 옮길 수 있습니다.
