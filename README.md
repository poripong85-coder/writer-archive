# 🍊 귤껍질 출판사

매일의 인사이트 조각을 모으는 작은 출판사 사이트입니다.
홈은 다마고치처럼 작은 도트 마을이고, 귤·별·연필·집 모양 건물이 각각 메뉴로 이어집니다.

| 건물 | 메뉴 | 내용 |
|---|---|---|
| 🍊 귤 | 귤껍질 소개 | 출판사 소개. 편집장이 화면에서 바로 고친다 |
| ⭐ 별 | 일상 모임 조각 | 모임 소개 2개 + 매일의 조각 기록장 |
| ✏️ 연필 | 사부작 책공장 | 편집장이 채우는 소개 글 + 브런치북·기사 링크 목록 (`app/pages/page.js` 의 `links`) |
| 🏠 집 | 시안북스테이 | 편집장이 채우는 소개 페이지 (비어 있으면 "준비 중") |
| 💬 하늘의 말풍선 | 와글와글 방명록 | 하늘 왼쪽(해·달 맞은편)에 떠 있다. 누구나 읽고, 로그인 없이 한마디 |

방문자는 로그인하지 않습니다. 메뉴에도 로그인 버튼이 없고, 편집장만 숨은 입구로 들어옵니다.
- 주소 끝에 `#editor` 를 붙여 열기 (예: `…/writer-archive/#editor`)
- 또는 오른쪽 위 설정(☀) → 맨 위 **편집장 로그인**

## 일상 모임 조각

**모임 소개** — 맨 위에 카드 두 장이 있고, 누르면 각 모임 소개 페이지로 갑니다.

| 모임 | 주소 |
|---|---|
| 눈사람 모빌 + 겨울 간식 모임 | `#meet-snowman` |
| 겨울 감 먹으며 새해 모임 나누기 | `#meet-persimmon` |

두 모임 모두 **오픈 준비중** 표시가 붙어 있습니다(`app/pages/page.js` 의 `status`). 편집장으로 로그인해 모임 페이지에서
**글 고치기**를 누르면 한 줄 소개와 본문을 바로 채울 수 있고, 한 줄 소개는 카드에도 그대로 뜹니다.

**눈사람 모빌 구매하기** (`#buy-snowman`) — 상품 정보는 [`app/shop.js`](app/shop.js) 한 곳에 있습니다.
사진·구성품·가격·구매 방법·주문 주소가 비어 있으면 '준비 중'으로 보이고, `buyUrl` 을 넣으면 구매하기 버튼이 켜집니다.

**귤껍질 기록장** — 편집장(관리자)만 쓰고, 모두 읽습니다.
- 편집장: `오늘 쓰기` · `달력` · `조각 모음` 탭. 카톡 '내게 쓰기'처럼 글·링크·사진을 던져두면 자정에 하루치가 조각으로 정리됩니다.
- 방문자: `달력` · `조각 모음`만 보입니다. 날짜를 누르면 그날의 조각이 열립니다.

자정 처리: 오늘 이전의 날은 곧 봉인된 날입니다. 앱을 켜둔 채 자정을 넘기거나, 며칠 만에 다시 열면 "지난번 이후 N일치가 조각으로 정리됐어요" 알림이 뜹니다.

## 와글와글 방명록

하늘 왼쪽, 해(낮)·달(밤) 맞은편에서 작은 별들에 둘러싸인 말풍선이 떠 있습니다. 누르면 `#guestbook`.

- 누구나 읽고, 로그인 없이 이름·도트 스탬프(귤·별·연필·집·하트)·한마디(300자)를 남깁니다.
- 글은 편집장이 지웁니다. 편집장 글에는 서버가 붙이는 **편집장** 배지가 달리고, 손님은 '편집장'이 들어간 이름을 쓸 수 없습니다.
- 도배 방지: 한 브라우저에서 1분에 3개, 서버에서는 손님 글 전체를 합쳐 1분에 6개 · 하루 300개까지 받습니다.
- 한마디를 남기면 **"귤에게 햇살 주기"(낮)** 또는 **"귤에게 별빛 주기"(밤)** YES / NO 를 묻습니다.
  YES 면 마을로 가서, 낮엔 해에서 햇살 조각이 · 밤엔 말풍선 둘레 별에서 별 조각이 포물선을 그리며
  귤 머리 위에 톡 떨어지고, 기기 화면에 고맙다는 인사가 뜹니다. NO 면 방명록에 그대로 머뭅니다.
  (움직임 줄이기 설정이면 날아오지 않고 바로 머리 위에 앉아요)

마을 하늘은 시간을 따릅니다: 낮엔 달 자리에 해, 저녁(17~19시)엔 해가 내려오며 노을빛, 밤엔 달과 별.

## 귤 하우스 집들이

`#gyul-house` — 픽토그램으로 하는 온라인 집들이. 홈 맨 아래 카드와 메뉴에서 들어갑니다.

1. 중문을 **똑똑**(두 번) 두드리면 간유리 너머로 귤 그림자가 다가오며 "누구세요~?"
2. 문짝이 한쪽으로 미끄러져 열리고 귤이 손을 흔들며 나옵니다
3. **집 구경 시작** → 방마다 픽토그램 장면 + 귤의 한마디 (← → 키, 옆으로 밀기도 됨)
4. 끝나면 방명록에 한마디 남기기로 이어집니다

중문 모양과 방 소개 글은 [`app/house.js`](app/house.js) 한 곳에서 고칩니다.
문짝 수(1~4)·열리는 쪽·아치형·문틀 색·유리 종류(투명/불투명/모루유리)·가로 살 위치·손잡이 색,
그리고 방 이름·대사·사진 주소(`photo`). 장면 그림은 `living · kitchen · study · bedroom · veranda` 중에서 고릅니다.

## 어디서 어떻게 돌아가나

같은 코드가 실행 환경을 스스로 판단합니다 (`app/env.js`).

| 환경 | 저장 위치 | 관리자 | 개인 기록장 |
|---|---|---|---|
| claude.ai 아티팩트 (로그인) | 공유 저장소 (db 기능) + 사진은 assets | 아티팩트 소유자 | 기록 권한 있는 사람마다 따로 |
| claude.ai 아티팩트 (로그아웃) | — | — | 로그인 안내만 표시 |
| 실제 주소 + `app/config.js` 설정 | Supabase (Postgres + 저장소) | `admins` 표에 넣은 계정 | 없음 (방문자는 로그인하지 않음) |
| 직접 띄움, 설정 없음 (`npm start`) | 이 브라우저의 IndexedDB | 실행한 사람 | 같은 브라우저 안에서 체험용 |

아티팩트에 선언한 접근 규칙:

```js
db: { rules: [
  { path: "", read: "view", write: "owner" },          // 공개 기록장·소개 글: 모두 읽기, 소유자만 쓰기
  { path: "data/users/{self}", write: "interact" },     // 각자의 기록장: 본인만 읽고 쓰기
]}
```

`fragments/<id>` 공개 조각 · `pages/<intro|factory|stay>` 소개 글 · `data/users/<id>/<entryId>` 개인 조각

### 공유 설정에서 알아둘 것

- 기록을 **보려면** claude.ai 로그인이 필요합니다. 로그아웃 상태면 마을과 메뉴만 보이고, 기록장 자리에 로그인 안내가 뜹니다.
- **나도 기록해보기로 쓰려면** 그 사람이 이 아티팩트에서 참여자(Contributor) 이상이어야 합니다. 권한이 없으면 쓰는 순간 "기록 권한을 요청해 주세요" 안내가 뜨고, 쓰던 글은 입력창에 남습니다.
  - 팀/엔터프라이즈 플랜: 조직 전체 공유를 참여자로 두면 됩니다.
  - 개인 플랜: 바깥 사람은 링크로 들어오면 읽기만 할 수 있습니다. 쓰게 하려면 이메일로 편집자 초대를 해야 하고, 이 경우 공개 링크는 꺼져 있어야 합니다.
- 방문자가 올린 사진은 조직 구성원에게만 보입니다(플랫폼 정책).

## 실제 주소로 배포

GitHub Pages + Supabase로 띄우면 로그인 없이 누구나 보고 방명록을 남길 수 있고, 편집장만 이메일 아이디+비밀번호로 로그인해 기록합니다.
순서는 [DEPLOY.md](DEPLOY.md)에 있습니다. 표와 권한 규칙은 [`supabase/schema.sql`](supabase/schema.sql) 하나를 실행하면 끝납니다.

## 로컬에서 띄우기

```bash
npm start      # http://localhost:5173
npm test       # 날짜 경계·파싱·통계·봉인 판정 순수 로직 테스트
```

빌드도 의존성도 없습니다. 정적 파일이라 어디에 올려도 됩니다(이때는 단독 모드).

## 예전 버전 데이터

이 기기에만 저장하던 예전 귤껍질의 조각이 남아 있으면, claude.ai에서 처음 열 때 어디로 옮길지 묻습니다
(공개 기록장 / 나의 기록장 / 나중에). 원본은 지우지 않으며, 설정에서도 언제든 다시 옮길 수 있습니다.
